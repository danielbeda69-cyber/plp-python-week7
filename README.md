
# PLP Week 7 Assignment: My Notes & The Report Builder

## Project Description

This project contains two Python programs that demonstrate file handling and CSV data processing.

## Project Files

- **my_notes.py** - Writes, appends, reads and counts notes.
- **my_notes.txt** - Stores the four notes created by the notes program.
- **report_builder.py** - Reads learner information from a CSV file and generates a report.
- **hubs.csv** - Contains learner names, hub names and scores.
- **report.txt** - Contains the generated learner report.
- **README.md** - Provides information about this project.

## File Handling Explanation

In Question 1, the "w" mode is used to create a new file and write the first three notes.

The "a" mode is used to add the fourth note without deleting the previous notes.

If "a" were changed to "w", the existing notes would be erased and replaced by the new note.
